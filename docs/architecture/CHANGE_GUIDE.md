# সহজ পাঠশালা — পরিবর্তন নির্দেশিকা (CHANGE GUIDE)
### "এক জিনিস, এক জায়গা" — যেকোনো কিছু পরিবর্তন করতে ঠিক একটি ফাইল খুলুন

> **এই ডকুমেন্টের গুরুত্ব:** এটি এই প্রজেক্টের সবচেয়ে গুরুত্বপূর্ণ এবং সর্বাধিক পঠিত নির্দেশিকা।
> আপনি সাইটের যে প্রান্তেই কোনো রং, ফন্ট, বাটন, লেখা, মেনু, নিয়ম বা মডিউল পরিবর্তন করতে চান না কেন, নিচের টেবিল দেখে সরাসরি নির্দিষ্ট ফাইলে হাত দিন।

## ২. পরিবর্তনের সাধারণ নিয়ম ও নির্দেশনাবলী (How to Execute a Change)

### উদাহরণ ১: প্রাইমারি ব্র্যান্ড কালার পরিবর্তন করতে চান
1. ওপেন করুন: `packages/design-tokens/src/semantic.css`
2. `--c-primary` এবং `--c-primary-soft` ভ্যারিয়েবলের মান আপডেট করুন।
3. ব্যাস! কোনো JSX বা কম্পোনেন্ট ফাইলে হাত দেওয়া লাগবে না। পাবলিক সাইট, অ্যাডমিন পোর্টাল, চার্ট, প্রিন্ট কপি সব একযোগে বদলে যাবে।

### উদাহরণ ২: নতুন একটি অ্যাডমিন মডিউল যোগ করতে চান (যেমন: লাইব্রেরি)
1. ওপেন করুন: `packages/config/modules.json`
2. একটি নতুন এন্ট্রি যোগ করুন:
   ```json
   {
     "key": "library",
     "route": "library",
     "icon": "book",
     "permission": "library.manage",
     "planModule": "standard",
     "navGroup": "academic",
     "order": 110,
     "labelKey": "admin.nav.library"
   }
   ```
3. ফ্রন্টএন্ডে ফিচার ফোল্ডার তৈরি করুন: `apps/web/src/features/library/admin/LibraryPage.tsx`
4. ব্যস! অ্যাডমিন সাইডবার, রাউটিং, অ্যাক্সেস গার্ড ও রোল পারমিশন চেকবক্সে এই মডিউল স্বয়ংক্রিয়ভাবে চলে আসবে।

### উদাহরণ ৩: বাটনের গোলাকার ভাব (Border Radius) সব জায়গায় কমাতে চান
1. ওপেন করুন: `packages/design-tokens/src/shape.css`
2. `--radius-btn` টোকেনের মান `10px` থেকে `6px` করুন।
3. পুরো অ্যাপের শত শত বাটনের রেডিয়াস সাথে সাথে ৬ পিক্সেল হয়ে যাবে।

## ৩. কনট্রাস্ট ও ভ্যালিডেশন চেকলিস্ট
যেকোনো পরিবর্তনের পর টার্মিনালে নিচের ভেরিফিকেশন রান করুন:
```bash
# ১. কালার কনট্রাস্ট ও থিম ভ্যালিডেশন
npm run test:tokens

# ২. টাইপস্ক্রিপ্ট ও কন্ট্রাক্ট চেক
npm run typecheck

# ৩. লিন্টার ও আর্কিটেকচার বাউন্ডারি রুল
npm run lint
```
