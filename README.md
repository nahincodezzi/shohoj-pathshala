# সহজ পাঠশালা (Sohoj Pathshala)
### মাল্টি-স্কুল প্ল্যাটফর্ম · প্রতিটা স্কুলের নিজস্ব CMS · ডার্ক/লাইট ডিজাইন সিস্টেম

> **ট্যাগলাইন:** সব স্কুল, এক সহজ প্ল্যাটফর্মে। (Every school, one simple platform.)  
> **ডিজাইন রেফারেন্স:** ক্যানভাস স্পেসিফিকেশন অনুযায়ী ডার্ক (ডিফল্ট) ও লাইট মোড, Emerald ও Indigo থিম  
> **লাইভ রিপোজিটরি:** `https://github.com/nahincodezzi/shohoj-pathshala`

---

## 🌟 প্ল্যাটফর্ম পরিচিতি
**সহজ পাঠশালা (Sohoj Pathshala)** একটি প্রোডাকশন-রেডি মাল্টি-স্কুল (Multi-Tenant) SaaS শিক্ষাপ্রতিষ্ঠান ব্যবস্থাপনা প্ল্যাটফর্ম। একটি মাত্র অ্যাপ ও স্টোরেজ ইঞ্জিন থেকে শত শত স্কুল পরিচালিত হয়, যেখানে:
- প্রতিটা স্কুলের জন্য রয়েছে নিজস্ব ব্রান্ডেড পাবলিক ওয়েবসাইট (`/:slug`, যেমন `/bdhs`)।
- প্রতিটা স্কুলের জন্য সম্পূর্ণ স্বাধীন অ্যাডমিন পোর্টাল (`/:slug/admin`)।
- কেন্দ্রীয় নিয়ন্ত্রণ ও পর্যবেক্ষণের জন্য রয়েছে দ্বিভাষিক Platform Owner প্যানেল (`/owner`)।
- এক স্কুলের ব্যবহারকারী বা ডেটা অন্য কোনো স্কুলের তথ্যের সাথে কখনোই মিশে না (কঠোর টেন্যান্ট আইসোলেশন)।

| **০৫** | **শিক্ষক ও কর্মচারী পরিষদ** | পদবি, যোগ্যতা, ফোন ও ইমেইলসহ পূর্ণাঙ্গ অ্যাকাডেমিক ও স্টাফ ডিরেক্টরি। |

- **স্কুল সুপার অ্যাডমিন:** `admin` / `password123`
- **প্রধান শিক্ষক:** `headmaster` / `password123`
- **সহকারী শিক্ষক:** `teacher` / `password123`
- **হিসাবরক্ষক / অফিস সহকারী:** `office` / `password123`

### ২. Platform Owner প্যানেল (`/owner`)
- **প্ল্যাটফর্ম ওনার:** `owner` / `owner123` (সর্বদা Indigo থিম)

## 🧭 রাউটিং ম্যাট্রিক্স (Routing Matrix)

| রুট | বিবরণ |
|---|---|
| `/` | প্ল্যাটফর্মের মূল ল্যান্ডিং পেজ (৮ মডিউল, অনবোর্ডিং ফ্লো, স্কুল নেটওয়ার্ক) |
| `/design` | ডার্ক ও লাইট মোড পাশাপাশি রেখে সব ডিজাইন টোকেন ও কম্পোনেন্টের ভিজ্যুয়াল শোকেস |
| `/owner` | প্ল্যাটফর্ম ওনার ড্যাশবোর্ড (নতুন স্কুল অনবোর্ডিং, সাপোর্ট মোড, অডিট লগ) |
| `/:slug` | যেকোনো স্কুলের পাবলিক ওয়েবসাইট (যেমন `/bdhs`, `/bahs`) |
| `/:slug/login` | নির্দিষ্ট স্কুলের নিরাপদ কর্মী লগইন স্ক্রিন (পাবলিক রেজিস্ট্রেশন নিষিদ্ধ) |
| `/:slug/admin` | নির্দিষ্ট স্কুলের অ্যাডমিন প্যানেল ও ৮টি ম্যানেজমেন্ট সাব-মডিউল |

## 💻 লোকাল ইনস্টলেশন ও রান করার নিয়ম

### ১. ডিপেন্ডেন্সি ইনস্টল
```bash
npm install
```

### ২. ডেভেলপমেন্ট সার্ভার চালু
```bash
npm run dev
```
ব্রাউজারে খুলুন: `http://localhost:5173/`

### ৩. প্রোডাকশন বিল্ড তৈরি
```bash
npm run build
```

## 🎨 ডিজাইন সিস্টেম ও কালার টোকেন
- **ডিফল্ট মোড:** ডার্ক মোড (`mode-dark`)
- **লাইট মোড:** এক ক্লিকে টগলযোগ্য (`mode-light`)
- **ডিফল্ট থিম:** Emerald (`theme-emerald`), ঐচ্ছিক Indigo (`theme-indigo`)
- **ফন্ট:** Hind Siliguri (হেডিং), Noto Sans Bengali (বডি), Inter (ইংরেজি/সংখ্যা)
- **প্রিন্ট ইঞ্জিন:** `@media print` ব্যবহার করে সাদা কাগজে কালো লেখা, অফিশিয়াল জলছাপ ও সিল-স্বাক্ষর সহ
