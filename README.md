# সহজ পাঠশালা (Shohoj Pathshala)
### Smart School Management System & Portal

---

## 🌟 Overview
**সহজ পাঠশালা (Shohoj Pathshala)** একটি আধুনিক, ক্লিন এবং সম্পূর্ণ স্বাধীন স্কুল ম্যানেজমেন্ট প্ল্যাটফর্ম। এটি সম্পূর্ণ নতুনভাবে শুরু করা হয়েছে যাতে কোনো বাহ্যিক ডাটাবেজ বা পূর্ববর্তী প্রজেক্টের সাথে কোনো প্রকার কনফ্লিক্ট বা ডিপেন্ডেন্সি না থাকে।

---

## 🔒 100% Isolated & Clean Architecture
- **No Remote Database Linked**: কোনো Supabase বা রিমোট ক্লাউড ডাটাবেজ কানেক্ট করা নেই।
- **Clean Environment**: কোনো পুরনো `.env` বা গোপন ক্রেডেনশিয়াল সংরক্ষিত নেই।
- **Ready for Custom Backend**: পরবর্তীতে পছন্দমতো Flask + PostgreSQL বা নিজস্ব ব্যাকএন্ড যুক্ত করার জন্য প্রস্তুত।

---

## 🚀 Tech Stack
- **Frontend Framework**: React 19
- **Bundler & Dev Server**: Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React

---

## 💻 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
